.. _ngidop_intro:

Введение
========

В руководстве содержатся общее описание серверного программного обеспечения NextGIS ID (NGIDOP - NextGIS ID on-premise) для своего сервера, организации доступа пользователей с учетом системы прав доступа сторонней организации.

NGID входит в поставку NextGIS Web `Standard/Extended <https://nextgis.ru/pricing/>`_ и устанавливается вместе с `NextGIS Web On-premise <https://docs.nextgis.ru/docs_ngweb/source/ngw_op.html>`_.
